# Quickstart (local)

Suba o stack local usando Docker.

## Pré-requisitos
- Docker Desktop instalado e em execução

## Rodar

macOS/Linux:
```bash
./setup.sh
```

Windows (PowerShell):
```powershell
.\setup.ps1
```

## Acesso
- App: http://localhost:8080
- API health: http://localhost:3001/api/health
- API Docs: http://localhost:3001/api-docs
